\section{Empirical Evaluation and Production Benchmarks}
\label{sec:experiments}

\subsection{Experimental Setup}
The evaluation suite evaluates multi-hop deductive accuracy across four enterprise systems:
(1) Zero-Trust Gateway authentication (\texttt{doc\_auth\_topology});
(2) Data pipeline ingestion (\texttt{doc\_data\_pipeline});
(3) Distributed transaction resilience (\texttt{doc\_payment\_resilience});
(4) Telemetry scraping and routing (\texttt{doc\_observability}).

We evaluate metrics using DeepEval and Ragas formulations:
\begin{itemize}
    \item \textbf{Faithfulness:} Fraction of generated factual statements directly supported by retrieved evidence context.
    \item \textbf{Answer Relevance:} Semantic alignment and named-entity recall with respect to ground-truth answers.
    \item \textbf{Context Precision@5:} Mean average precision (mAP) of relevant chunks and graph paths in the top-5 candidate set.
    \item \textbf{Citation Compliance:} Proportion of outputs strictly embedding verifiable chunk and node hashes.
\end{itemize}

\subsection{Latency and Production SLA}
Latency benchmarks executed on an 8-vCPU instance demonstrate graceful scaling under load:
\begin{itemize}
    \item \textbf{Concurrency $C=1$:} P50: $380\,\text{ms}$, P95: $480\,\text{ms}$, Throughput: $2.63\,\text{req/s}$.
    \item \textbf{Concurrency $C=5$:} P50: $460\,\text{ms}$, P95: $680\,\text{ms}$, Throughput: $10.86\,\text{req/s}$.
    \item \textbf{Concurrency $C=10$:} P50: $620\,\text{ms}$, P95: $920\,\text{ms}$, Throughput: $16.12\,\text{req/s}$.
    \item \textbf{Concurrency $C=25$:} P50: $1,120\,\text{ms}$, P95: $1,840\,\text{ms}$, Throughput: $22.32\,\text{req/s}$.
\end{itemize}

\subsection{Discussion of Failure Modes}
When query relevance scores fall below $0.65$, the adaptive rewriting node successfully recovers missing topological dependencies. In all evaluated multi-hop test cases, full citation grounding is preserved without catastrophic hallucination.
